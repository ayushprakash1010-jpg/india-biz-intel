# India BizIntel

AI-powered corporate news intelligence platform for India business events.

## Topics Covered
- Funding rounds
- Leadership changes (appointments and exits)
- Entry in India (global companies entering Indian market)
- Business Expansion
- Mergers and Acquisitions
- GCC Setup

## News Sources
- MoneyControl
- Economic Times
- Business Standard
- BCG / Bain / Kearney (industry outlook)

## Tech Stack
- API: NestJS + Prisma + PostgreSQL + BullMQ + Redis + Qdrant
- Web: Next.js 14 (App Router) + Tailwind CSS
- AI: Google Gemini
- Monorepo: Turborepo + pnpm workspaces
